# StockFlow – Inventory Management System

A modern and responsive inventory management system built with **React.js, Tailwind CSS, and React Router**.

StockFlow provides a clean dashboard for managing products, categories, suppliers, orders, and inventory levels.

## ✨ Features

- 📊 Dashboard with inventory statistics
- 📦 Product management
- 🏷️ Category management
- 🚚 Supplier management
- 🛒 Order management
- 🔎 Product and order search
- 🎯 Category and status filtering
- ⚠️ Low-stock monitoring
- 📈 Sales overview chart
- 🔔 Notifications
- 💾 LocalStorage data persistence
- 📱 Responsive design

## 🛠️ Technologies

- React.js
- React Router
- Tailwind CSS
- Recharts
- Lucide React
- Vite
- JavaScript
- LocalStorage

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sabreenalkass/stockflow-inventory-management.git
```

Navigate to the project:

```bash
cd stockflow-inventory-management
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 💡 Purpose

StockFlow was developed as a portfolio-ready example of a modern inventory management interface.

The project demonstrates practical frontend development skills including reusable React components, state management, routing, responsive UI design, filtering, CRUD operations, local data persistence, and dashboard visualization.
